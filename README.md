# Аналитика пути покупателя в интернет-магазине

Учебный проект на Python: генерация синтетических событий, анализ воронки покупки, удержания, когорт и A/B-эксперимента.

Все данные здесь создаются искусственно. Проект не связан с внутренними данными Ozon и не описывает реальные показатели компании.

## Бизнес-вопросы

1. На каком шаге пути от просмотра товара до покупки теряется больше всего пользователей?
2. Как удержание D1, D7 и D30 меняется между когортами регистрации?
3. Отличается ли конверсия в покупку между контрольной группой и группой с упрощённым оформлением?
4. Как конверсия различается по каналу привлечения и платформе?

## Что делает проект

- Создаёт таблицы пользователей и событий с фиксированным seed для воспроизводимости.
- Считает воронку по уникальным пользователям.
- Рассчитывает точное удержание на D1, D7 и D30.
- Строит когортную таблицу по месяцу регистрации.
- Сравнивает конверсию A/B-групп, считает z-статистику, p-value и 95% доверительный интервал.
- Сохраняет таблицы, графики и сводку в папку reports.

## Запуск

Нужен Python 3.10 или новее.

    python -m venv .venv

Windows:

    .venv\Scripts\activate

macOS/Linux:

    source .venv/bin/activate

Установите библиотеки:

    pip install -r requirements.txt

Сгенерируйте данные:

    python -m src.generate_data

Рассчитайте метрики и сохраните отчёты:

    python -m src.analyze

## Как читать метрики

### Воронка

Для каждого этапа считается число пользователей, у которых встретилось соответствующее событие. Конверсия от начала — доля от всех зарегистрированных. Конверсия от предыдущего шага помогает увидеть локальный отток.

### Удержание

D7 — доля пользователей, у которых есть хотя бы одно событие ровно через семь дней после регистрации. В знаменатель входят только пользователи, для которых к концу периода уже прошло семь дней. Такой подход не считает ещё не дозревших пользователей как не вернувшихся.

### Когорты

Пользователи группируются по месяцу регистрации. Для каждого месяца активности считается доля исходной когорты, у которой в этом месяце было событие. Так можно сравнить возврат пользователей, пришедших в разные месяцы.

### A/B-тест

Конверсия группы — доля пользователей с событием purchase среди всех назначенных в эту группу. Разница считается как treatment минус control. Доверительный интервал показывает диапазон значений разницы, совместимых с наблюдаемыми данными. p-value оценивает, насколько необычна такая разница при нулевом эффекте.

Так как данные полностью сгенерированы, статистическая значимость здесь демонстрирует расчёт, а не доказывает эффект реального изменения продукта.

## Важные ограничения

- Синтетическая симуляция не заменяет анализ реального продукта.
- Правила генерации задают структуру событий и различие A/B-групп заранее.
- Результаты зависят от seed и параметров в src/config.py.
- Корреляция сегментов с конверсией не доказывает причинный эффект.
